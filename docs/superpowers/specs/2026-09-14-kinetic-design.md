# Quantum Branding: kinetic field

The owner explicitly authorizes a new visual direction, including replacing the
box, inspired by Google Labs. Preserve every current editorial string, link,
metadata field, bilingual route and the latest sign mapping. No price changes.

## Direction

Three approaches considered: add motion to the existing box (too small a change),
replace the site with full-screen video (expensive and poor for reading), or build
a kinetic field with a distinctive sculpture and native interactive objects.
Choose the third. Retain DM Sans, Instrument Serif, blue/paper/acid and dark Lab.

The home hero introduces a Picsart-generated open blue ribbon sculpture with an
acid core. Six existing illustrated tools sit in a quiet strip. Brief entrance
sequences, subtle pointer depth and scroll offsets create presence. The mark remains
the only BrandOS icon. The compass stays in the hero, Collapse and Business only.

Lab becomes a spacious instrument gallery with framed scenes: a floating stamp for
BrandOS, a paper instrument for Brief, scanning rings for SignalScan. Territories
become a six-card visual grid. Case covers gain restrained layered depth. About
retains the founder poster. Thinking gains a visually articulated index; essays
remain easy to read. Inner page headings have short entrances and spacious type.
The owner's mid-task clarification is authoritative: simple, contemporary motion,
never kitsch. No rotating logo, exaggerated bounce or decorative header diagrams.

## Motion contract

Content is readable with JS off. Enhancements use finite Web Animations reveals,
CSS transforms, IntersectionObserver and one requestAnimationFrame per active
pointer/scroll update. Never intercept scrolling or internal navigation. Native
CSS page entrances enhance ordinary browser navigation. No custom
cursor or essential information on hover. Pause ambient animations offscreen and
in hidden tabs. Reduced-motion users receive a composed static design with no
entrances, drift, pointer depth or transitions; listen for preference changes.
All automatic animation runs once in 480 to 1100ms, without idle loops. A shared
pending frame batches scroll and pointer writes. Content is never CSS-hidden.
